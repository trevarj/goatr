## Source-backed decisions

- Herdr `3d9d2b18dab139ba226ebc5a1c9a9f2c9c3ee4df` (0.9.3) supplies local NDJSON topology/control, not a universal conversation protocol. `agent.prompt` is PTY automation; do not use terminal reads/keys for the native conversation/approval path. Reference: https://github.com/herdrdev/herdr/tree/3d9d2b18dab139ba226ebc5a1c9a9f2c9c3ee4df .
- Stock OMP 18.6.1 collaboration protocol 3 already controls the exact running interactive process. Its persisted entries, transient events, prompt/abort and select/editor dialogs are reusable; custom dialogs, full rich-ask metadata and exact tool-approval arguments are not universally available. Read the installed `@oh-my-pi/pi-coding-agent` package's `src/collab/`, `src/modes/controllers/extension-ui-controller.ts`, and the resolved `@oh-my-pi/pi-wire` dependency's `src/index.ts`; locate the actual package roots in the deployment rather than assuming an npm prefix.
- Stock Codex 0.159.1, upstream `8e68a98ef03cdde76d2e6800791ebdf1b3b95b24`, supports concurrent clients of the same app-server. Existing embedded TUIs have no external attachment endpoint; never cold-resume them in a second process and call it live attachment. https://github.com/openai/codex/tree/8e68a98ef03cdde76d2e6800791ebdf1b3b95b24/codex-rs/app-server .
- AgentWire is not needed as a deployed service. Its local reference checkout at revision `68d1cb39ffddb5a39530ea8d918743f0452aedc0` informed provider-operation/receipt patterns and declares MIT metadata; no verified public source URL is recorded and the source is not bundled here. Obtain authorized source access and the full license notice before reuse; do not copy its IRC transport, channel-global binding, lossy approval projection or spawn-on-attach fallback.
- Roamgate `8de13620a3e9d22c7c40f95f01dd08b45d06b886` validates the shared-Herdr bridge model, but its mobile composer still sends pane input and its Ranger assistant is a separate session. Do not embed its terminal or substitute Ranger for the user's live agent. https://github.com/powerfooI/roamgate/tree/8de13620a3e9d22c7c40f95f01dd08b45d06b886 .
- SSH can carry structured data but does not remove reachability requirements; Termux RUN_COMMAND returns completion results rather than a duplex stream; Mosh synchronizes terminal screens and requires reachable UDP. Tailscale adds a phone VPN/app; Cloudflare Quick Tunnels are testing-only. These were investigated and are not additional Goatr transports.
- Iroh public relays are an accepted personal/hobby dependency with rate limits and no SLA. Traffic is encrypted end-to-end; relays/discovery still observe metadata. https://docs.iroh.computer/iroh-services/relays/public .

## Reuse and license obligations

Goatr's chosen license remains GPL-3.0-or-later. Before copying each permitted seam, record source revision/path and retain copyright/license/NOTICE obligations in distributions. OMP installed LICENSE was inspected as MIT with Mario Zechner/Can Bölük/Stencil Labs notices; preserve them when porting parser/crypto/relay mechanics. MOTD LICENSE text is GPLv3; inspect per-file headers/project grant before copying the three QR/lifecycle seams, preserve notices and supply corresponding modified source/build instructions. AgentWire local `pyproject.toml:11` declares MIT, but no root LICENSE was located: recover/retain the pinned copyright and full license notice before copying its helper code. License metadata alone does not supply that notice.

FFI tree exposes MIT/Apache license files; select and retain the applicable upstream license/notice terms for patched binding sources. Verify Codex generated-schema license/notice provenance before checking in the small used fixtures/projections; do not import its whole schema as a runtime framework. Inspect transitive packaged-library notices (including JNA/Markwon/UniFFI) during native/package gate. Reading Herdr/wrapper/reference behavior does not authorize copying unrelated implementation or deployment modules. No reference tree is modified.

## Reference limitations

Installed-package locations and local-reference revisions record source provenance from the original plan; personal absolute paths and private repository identifiers have been omitted. Those sources are not bundled Goatr inputs or proof that any available checkout matches the documented revision. AgentWire, MOTD and the private deployment reference have no verified public source URL in this plan; obtain authorized source access before relying on or copying their implementations, and report unavailable sources as an implementation prerequisite rather than inventing an upstream URL. Check actual installed versions, wrapper paths, sandbox namespaces and source availability during implementation; apply the [main contingencies](GOATR_PLAN.md#assumptions--contingencies) if they differ. Core source line numbers are location hints for the pinned version, not stable APIs.

Planning revision evidence consists of document review, the audit's explicitly named source inspections, additional immutable Herdr/Codex/FFI/core/schema reads, OMP registry/title/persistence reads, and wrapper HEAD/origin/local-content inspection. No Goatr build, lint, test, provider launch or service installation was executed. Protocol, retention, manifests and work packages are proposed Goatr contracts; feasibility/runtime gates in [Testing](TESTING.md) must not be relabelled as passed source verification.
