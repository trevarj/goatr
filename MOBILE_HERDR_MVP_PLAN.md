## Goal and settled scope
Complete Goatr's existing Android/Rust application so the physical phone can discover, display, create, and control real OMP and Codex sessions and ordinary Herdr terminals. Closely adapt Orca's mobile presentation while preserving structured agent controls. Agent Terminal becomes a strictly read-only ANSI observer; ordinary-shell Terminal remains interactive and gains real native history. Acceptance includes the connected Mi 9T, independent-network connectivity, and both Persistent and socket-free ntfy delivery. No emulator or fake provider is acceptable.

The latest owner decisions supersede the former private-native plan:

1. **Use the currently installed Herdr unchanged.** No Herdr patches, replacement builds, native schema/protocol changes, receiver instrumentation, profile override, installation, daily-unit change or desktop deployment. Isolated acceptance runtimes must execute the qualified installed binary, not a copied/rebuilt diagnostic substitute.
2. **Omit native Close for every target and omit preserved empty-workspace retention.** There is no split-only substitute, final-pane test, empty-workspace restart test or first-terminal-after-final-Close requirement. Do not expose `session.close`, `shell.close`, NativeClose receipts, pane-close grants or Close fences. Provider **Stop**, ordinary-shell **Release**, and dismissing a viewer remain distinct existing operations; none is relabeled Close.
3. **Use stock `ObserveTerminal` for agent Terminal**, accepting a new bounded ANSI DISPLAY decoder rather than native styled-cell parity or nonexistent bound-grid APIs. The coordinator must review the new renderer/security architecture before implementation.
4. **Use stock public-socket `pane.scroll` for ordinary-shell history**, accepting a shared native viewport, serialized Goatr lease, pre/post route validation, response-identity checks and truthful uncertainty. There is no actor-consumed terminal/grant-epoch fence or independent per-phone history promise.
5. **Keep native22, endpoint generation1, Goatr `goatr/2`/envelope2, DB8, pairing/admin1 and existing action fingerprints.** Old-payload/daily-companion compatibility remains a source contract, not an assertion that this fresh physical path preserved user-removed pre-uninstall Goatr data. No v3 incompatibility cutover.
6. **Use the approved official F-Droid ntfy1.25.2 fixture and completed same-key package upgrade.** Its independently authenticated package-continuity facts/limitations remain below. The user intentionally removed Goatr PRODUCT; current physical admission is fresh-only, never a restored-product fallback. Neutral config uses an independent caller pin, and all real-host/device/provider/notification acceptance gates still apply.

These are resolved scope decisions, not questions to ask again. All other compatible provider, creation, UI, security, resource, retention and physical-notification criteria below remain required.
