# Complete the mobile Herdr MVP

## Context
Complete Goatr's existing Android/Rust application so the phone can discover, display, create, and control OMP and Codex sessions and ordinary Herdr terminals. Closely adapt Orca's mobile UI, retain structured agent controls, add passive agent Terminal viewing, and finish fully interactive ordinary terminals including native scrollback and full-screen TUIs. Safe Close must remove exactly the selected pane, including a workspace's final pane, while preserving that workspace, its worktree/files, and every other pane. Acceptance requires the connected physical Mi 9T, away-home connectivity, and both persistent-service and socket-free ntfy notifications; no emulator.

## Decisions and execution ownership
- **Coordinator:** m1 / GPT-5.6 Sol / xhigh. **Code writer:** m2 / GPT-6.1 Sol / xhigh. Use one implementation writer at a time. Coordinator assigns bounded path leases, owns shared-contract decisions, reviews handoffs, and runs validation; workers do not recursively delegate or run builds/tests/formatters mid-flight. An independent read-only m2 correctness review precedes each security/contract handoff. Tool effort `hi` is not evidence that the requested model reasoning setting is xhigh; configure the actual named model accordingly before implementation.
- Update the existing `io.github.trevarj.goatr.debug` and `.debug.test` packages using the same signer. **No separate MVP app variant.** Preserve application data, installation/host keys, pairings, routes, actions, and recovery history. The user accepts that the unchanged daily v2 companion becomes incompatible after the phone moves to v3. Retain pairing without Forget/re-pair; display the factual requirement `This build requires a Goatr v3 companion`. Label a failure incompatible only when its typed ALPN/version error proves that; generic dial failures remain connection failures.
- Use a **private owned patched Herdr and v3 companion**, paired as one additional host. Leave installed Herdr, daily companion units/configuration, existing desktop sessions, and the unrelated `.debug.verify` package untouched. No commits, pushes, PRs, profile installation, desktop deployment, or broad process cleanup is authorized.
- Agent Chat owns prompts, native requests/approvals, Stop, and provider options. Agent Terminal is passive and has no raw keyboard, resize, or shell-control fallback. Ordinary shell Terminal is interactive.
- Close may remove the selected pane's now-empty tab, but **must preserve its workspace**, including an empty workspace. Do not prune an empty workspace, close a worktree group, spawn a replacement shell, or limit Close to split panes.
- Official ntfy installation and public `https://ntfy.sh` are authorized. Both delivery modes must pass. Push contains HMAC-authenticated identifiers/category, not conversation content; HMAC does not encrypt metadata.
- Human-assisted QR camera, actual IME/paste/TUI interaction, network switching, and app-specific notification setup are acceptance steps, not grounds to substitute an emulator or fake input evidence.
